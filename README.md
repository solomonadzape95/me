# thesolenoid.space

Solomon Adzape’s personal portfolio: projects, experience, and the things I’m currently building.

![Portfolio preview](./public/portfolio-preview.jpg)

Built with Next.js, React, TypeScript, Tailwind CSS, Maple Mono, and Selera.

## Run locally

```bash
pnpm install
pnpm dev
```

Project content lives in `public/content/projects`. Last.fm listening status is enabled with `LASTFM_API_KEY` and `LASTFM_USERNAME` in `.env.local`.

```bash
pnpm typecheck
pnpm lint
pnpm build
```
